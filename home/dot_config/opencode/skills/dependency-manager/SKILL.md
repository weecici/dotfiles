---
name: dependency-manager
description: Use pnpm, astral-uv as the package/dependency manager for your project.
---

If you want to interact with **JS/TS** dependencies, use `pnpm`:
- Add dependencies: `pnpm add <package-name>`
- Remove dependencies: `pnpm remove <package-name>`
- Run scripts: `pnpm run <script-path>`

If you want to interact with **Python** dependencies, use `uv` (astral-uv):
- Add dependencies: `uv add <package-name>`
- Remove dependencies: `uv remove <package-name>`
- Run scripts: `uv run <script-path>`
